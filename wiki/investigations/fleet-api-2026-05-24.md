# Fleet API

## Summary

CODEX-T adds an additive Rust `Fleet<PlcId>` API for managing multiple actor-backed `Client` handles. It does not replace the older `PlcManager` pool or the wrapper-level FFI registry.

## Current Understanding

- `confirmed`: `Fleet<PlcId>` stores one cloneable actor `Client` per PLC id.
- `confirmed`: `Fleet::events()` forwards per-client `ConnectionEvent` values as `FleetEvent { plc_id, event }`.
- `confirmed`: `Fleet::check_health()` runs health checks across all currently registered PLC clients and returns a per-id result map.
- `confirmed`: the API is additive and does not alter `PlcManager`, C#, Python, or FFI behavior.
- `unclear`: whether `PlcManager` should eventually become a compatibility shim over `Fleet`, or remain a separate low-level pool.
