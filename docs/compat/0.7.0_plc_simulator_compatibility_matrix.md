# 0.7.0 PLC and Simulator Compatibility Matrix

Updated: `2026-03-22`

This matrix documents **current known compatibility** for `rust-ethernet-ip` across:
- Real Allen-Bradley PLC families
- Vendor simulators (for developer workflows)
- In-repo deterministic simulator used for regression testing

Release context:
- Stable published line: `0.6.3`
- Active hardening line: `0.7.0` (unreleased)

## Compatibility Matrix

| Target Platform | Connect/Session | Read/Write Primitive Tags | Discovery APIs (`discover_tags*`) | Route Path | UDT Workloads | Current Status |
|---|---|---|---|---|---|---|
| ControlLogix (real PLC) | Supported | Supported | Supported on tested targets | Supported | Supported (with known firmware limits) | **Primary supported target** |
| CompactLogix / GuardLogix (real PLC) | Supported | Supported | Generally supported; verify per firmware/project profile | Supported | Supported (with known firmware limits) | **Supported; validate per deployment** |
| Micro850 / CCW simulator profile | Partially supported | Primitive reads observed in issue reports | Discovery interoperability gaps reported | Not validated as full parity target | Partial | **Known gaps; see open issues** |
| In-repo deterministic simulator (`tests/plc_sim.rs`) | Supported (test harness) | Supported for modeled types/scenarios | Limited to modeled scenarios | Supported for route-path compatibility tests | Supported for modeled regression paths | **Test-only fixture, not a full PLC emulation** |

## Important Notes

1. **Real PLC validation is required before production use**, even when simulator tests pass.
2. The in-repo simulator is designed for deterministic CI-style regression checks, not exhaustive protocol emulation.
3. Some behavior differences in Micro850/CCW simulation can come from simulator profile limitations and/or implementation gaps.
