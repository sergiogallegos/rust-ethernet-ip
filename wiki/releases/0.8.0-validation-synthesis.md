# 0.8.0 Validation Synthesis

## Summary

`0.8.0` is not released, but the current draft line has passed a follow-up routed ControlLogix validation on 2026-04-16 for the exercised Rust core and C# wrapper feature sets.

No new real-hardware protocol regression was found. The remaining full-matrix failures match documented PLC firmware limitations around direct `STRING` writes and direct UDT-array-member writes.

## Current Understanding

- `confirmed`: Rust core validation on `1756-L81ES` via `1756-EN3TR` slot `0` passed the exercised feature set on 2026-04-16.
- `confirmed`: C# wrapper validation on the same target passed the exercised feature set on 2026-04-16.
- `confirmed`: Both Rust and C# full tag matrices produced 333/392 passed and 59 expected firmware-limited write failures.
- `confirmed`: Rust full workspace tests passed after the real-PLC run.
- `confirmed`: C# wrapper tests passed 41/41 after the real-PLC run.
- `confirmed`: A C# validation-example portability issue was found and fixed: macOS runs now copy `librust_ethernet_ip.dylib` rather than expecting the Windows `rust_ethernet_ip.dll`.
