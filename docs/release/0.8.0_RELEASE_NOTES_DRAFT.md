# 0.8.0 Release Notes Draft

Status: draft; `0.8.0` has not been released.

Last updated: 2026-04-19

## Scope

`0.8.0` is currently shaping up as the next planned release line, reflecting a larger scope that now includes toolchain modernization, packaging and release automation, documentation traceability, Python/data-platform expansion, diagnostics/schema work, examples/demos, and additional feature work beyond the `0.7.0` release.

No public Rust API break has been identified in the current delta from `v0.7.0`.

## Changes Since `v0.7.0`

### Packaging and Release Automation

- Added a Windows-first GitHub Actions release workflow for NuGet packaging and tagged publish.
- Added `scripts/pack-nuget.ps1` for Windows `win-x64` native runtime packaging.
- Added `scripts/pack-nuget.sh` for local macOS native runtime package staging.
- Fixed NuGet publish lookup on Windows by resolving the generated `.nupkg` path before invoking `dotnet nuget push`.
- Updated C# wrapper packaging metadata:
  - package builds as a library
  - package license is aligned to MIT
  - package README is included
  - native library artifacts are marked as content for runtime packaging
- Fixed C# wrapper validation examples on macOS by replacing stale `$(OS) == OSX` / Windows-only DLL copy rules with `MSBuild::IsOSPlatform(...)` checks.

### Documentation

- Documented the `RustEtherNetIp` NuGet package in the main README.
- Added the CLI install command for the NuGet package.
- Documented current NuGet packaging constraints:
  - managed wrapper targets `.NET 10`
  - packaged native runtime asset currently targets Windows `win-x64`
- Updated version-management release instructions to use the Windows-first NuGet pack/publish flow.
- Rechecked official Rockwell EtherNet/IP/data-access documentation on 2026-04-16 and updated source traceability.

### Maintainer Wiki

- Added `AGENTS.md` with repository-specific instructions for maintaining the LLM-maintained wiki.
- Added `wiki/` as a maintainer synthesis layer distinct from `README.md`, `docs/`, and `CHANGELOG.md`.
- Seeded wiki pages for:
  - controller and firmware behavior
  - route-path behavior
  - STRING and UDT write limitations
  - Rust/C# wrapper parity
  - `0.7.0` validation synthesis
  - LLM knowledge-base maintenance pattern
  - MacBook dashboard demo strategy

### Demos and Examples

- Expanded the MacBook manufacturing dashboard demo under `examples/web_app`.
- Added frontend lockfile coverage for reproducible installs.
- Added backend data ignore rules for runtime-generated demo state.
- Applied `cargo fmt` cleanup to touched Rust example files.

### Python and Data-Platform Layer

- Added an in-repo Python wrapper built on the existing Rust FFI boundary.
- Added Python unit tests and simulator-backed integration-test support.
- Added Python examples for:
  - single-tag reads
  - batch reads
  - CSV logging
  - SQLite logging
  - pandas/dataframe workflows
  - FastAPI service
  - collector service
  - MQTT snapshot publishing
- Added a Python-side simulator launcher example and local Docker example stacks for API/collector/MQTT packaging.

### Schema Export and Diagnostics

- Added Rust-side schema export structs and `export_schema()` / `export_schema_json()`.
- Added a first Rust-side diagnostics snapshot, explicit passive/verified health mode, and first-pass operational error categories.
- Exposed diagnostics snapshots through FFI and mapped them into thin C# and Python wrapper types.

### Cleanup and Fixes

- Added Obsidian workspace ignore coverage.
- Cleaned Rust 1.95 Clippy warnings in:
  - FFI write helper return handling
  - packed BOOL-array bit-index calculation
- Moved the repository baseline to Rust `2024` edition with `rust-version = "1.95"`.
- Updated Rust 2024 FFI exports to `#[unsafe(no_mangle)]` without changing the native symbol contract consumed by the C# wrapper.
- Refactored async/drop-order-sensitive paths ahead of the edition bump so subscription, tag-group, desktop-app, and manager flows remain explicit under Rust 2024 semantics.
- Refreshed dependency baselines on the Rust `1.95` toolchain, including the example web backend on `axum 0.8` / `tower-http 0.6`.
- Updated build/docs references from stale Rust `1.70+` and old C# `net8.0` paths to the current Rust `1.95` / `.NET 10` baseline.
- Changed README logo image references to absolute GitHub raw URLs so crates.io can render the package logo.
