# 0.7.0 Validation Synthesis

## Summary

`0.7.0` is confirmed on real hardware for the main Rust library paths across one CompactLogix and one ControlLogix target. Remaining failures are documented controller/firmware limitations, not release regressions.

## Current Understanding

- `confirmed`: The `0.7.0` hardening gate is closed with real-hardware evidence on both tested PLC families.
- `confirmed`: Main read/write, batch, subscription, health-check, tag discovery, route-path, and UDT-read paths were exercised successfully on both targets.
- `confirmed`: The remaining observed failures are direct writes to standalone `STRING` tags, direct writes to `STRING` members inside UDTs, and direct writes to UDT array element members.
- `likely`: The current production-safe guidance is to use read-modify-write for whole UDTs or whole UDT array elements when these restricted paths are involved.

## Tested Targets

- CompactLogix `5069-L320ERMS3`, firmware `35`, direct connection to `192.168.0.1:44818`
- ControlLogix `1756-L81ES`, firmware `37`, routed through `1756-EN3TR` slot `0` at `192.168.0.101:44818`

## Feature Coverage

- Connection, disconnect, and reconnect baseline
- Primitive reads and writes on controller-scoped and program-scoped tags
- Batch read, batch write, and mixed execute
- Subscription creation and polling behavior
- Health-check APIs
- Tag discovery, cache clear, and repopulation
- Route-path configuration and routed client creation
- UDT reads used by the current test tags
- Array element addressing including BOOL-array handling
- Arrays of UDTs and nested member access

## Performance Takeaways

- `confirmed`: Batch reads were materially more efficient than repeated single reads on both tested controllers.
- `confirmed`: Batch writes also improved effective logical throughput on both tested controllers.
- `confirmed`: The routed ControlLogix path did not show an obvious functional regression in the exercised scenarios.
- `needs-care`: These numbers are hardware-specific baselines, not general product claims.
