## #1 Routing support request

URL: <https://github.com/sergiogallegos/rust-ethernet-ip/issues/1>

Current assessment:
- The original complaint (slot-0-only / no routing) appears mostly addressed by route-path support added in `0.6.x`.
- Remaining risk is edge coverage for more complex multi-hop topologies.

Recommended action:
- Keep open only if there is still an untested multi-hop scenario known to fail.
