# 0.8.0 Validation Synthesis

## Summary

`historical`: `0.8.0` was an unreleased draft later absorbed into `1.0.0`.
This page preserves its 2026-04-16 routed ControlLogix validation evidence; it
is not the current release-status source.

On 2026-04-20, a narrower ControlLogix follow-up for the new schema, diagnostics, and Python-facing surfaces confirmed routed Rust and C# health/diagnostics behavior and materially reduced the remaining draft-line validation block.

Current blockers are:

- `confirmed`: routed Rust `export_schema()` now succeeds on the `1756-L81ES` target after fixing the malformed request shape, adding paged Symbol Object discovery, and implementing paged Template Object reads
- `confirmed`: routed schema export now returns both top-level tags and UDT definitions on that target; the remaining warning is limited to target-address omission in the export metadata
- `confirmed`: the Python real-PLC blocker was route-path support in the wrapper layer and is now cleared for routed ControlLogix reads, diagnostics, and collector runs
- `confirmed`: routed Python `STRING` reads now decode live Logix `STRING` payloads to plain text in both single and batch reads
- `confirmed`: MQTT snapshot publishing has now passed end to end on the routed `1756-L81ES` target with a local Mosquitto broker and observed subscriber payload
- `confirmed`: the earlier `gTestArray_DINT[5..7]` mismatches in the large C# validation app were caused by concurrent live writers during validation, not by a library regression
- `confirmed`: a final serial release-gate rerun on 2026-04-20 left no open live regressions on the exercised Rust/C#/Python surfaces
- `optional`: Docker example-stack validation is no longer treated as a release blocker for the Rust/C#/Python library surfaces

## Current Understanding

- `confirmed`: Rust core validation on `1756-L81ES` via `1756-EN3TR` slot `0` passed the exercised feature set on 2026-04-16.
- `confirmed`: C# wrapper validation on the same target passed the exercised feature set on 2026-04-16.
- `confirmed`: Both Rust and C# full tag matrices produced 333/392 passed and 59 expected firmware-limited write failures.
- `confirmed`: Rust full workspace tests passed after the real-PLC run.
- `confirmed`: C# wrapper tests passed 41/41 after the real-PLC run.
- `confirmed`: A C# validation-example portability issue was found and fixed: macOS runs now copy `librust_ethernet_ip.dylib` rather than expecting the Windows `rust_ethernet_ip.dll`.
- `confirmed`: On 2026-04-20, routed Rust `check_health()`, `check_health_detailed()`, and diagnostics snapshots were healthy on the same ControlLogix target.
- `confirmed`: On 2026-04-20, routed Rust route-path feature tests also passed on the same ControlLogix target.
- `confirmed`: On 2026-04-20, routed C# `CheckHealth()`, `CheckHealthDetailed()`, and diagnostics snapshots were healthy on the same ControlLogix target.
- `confirmed`: On 2026-04-20, the C# wrapper smoke example, benchmark, and full routed validation app passed on the same ControlLogix target; the full app returns `333/392` when run in isolation, and the remaining `59` non-passes are limited to expected STRING/UDT-array-member write limitations.
- `confirmed`: On 2026-04-20, the transient `gTestArray_DINT[5..7]` mismatches were traced to running multiple live write-heavy wrapper validations in parallel against the same PLC tags.
- `confirmed`: On 2026-04-20, the Python wrapper initially failed to load diagnostics because the local cdylib was stale and missing `eip_get_diagnostics_json`; rebuilding the native library fixed that load issue.
- `confirmed`: On 2026-04-20, Python route-path support was added using the existing FFI routed-connect entry point.
- `confirmed`: On 2026-04-20, routed Python single reads, batch reads, diagnostics, and the collector example worked on the same target; the collector wrote `4` rows in the one-shot validation pass.
- `confirmed`: On 2026-04-20, routed Python `STRING` reads were then normalized so the same target now returns plain-text `gTest_STRING` values in both single and batch reads.
- `confirmed`: On 2026-04-20, the MQTT publisher example completed a broker-backed one-shot publish against the same routed target and the subscriber observed topic `factory/lab/plc/controllogix-l81es/snapshot` with live `gTest*` values and empty `errors`.
- `confirmed`: On 2026-04-20, routed schema export returned `43` top-level tags, `9` UDT definitions, and preserved the route path on the same target after paged Symbol and Template Object reads were added.
- `confirmed`: On 2026-04-20, routed Template Object reads on this target required `Template Read (0x4C)` request data encoded as `offset:u32 + byte_count:u16`; size-only requests returned `0x13 Not enough data`.
- `confirmed`: On 2026-04-20, a final serial release-gate pass re-ran Rust schema/discovery/health/route-path checks, C# smoke/benchmark/full validation, and Python unit/live/collector checks without uncovering any new live regressions.
