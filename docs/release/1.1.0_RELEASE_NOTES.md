# rust-ethernet-ip v1.1.0

A post-1.0.0 correctness, cleanup, and feature release. **No breaking changes**
to the public Rust API or the C ABI — the ABI version stays `1` (a new
capability bit `CAP_LAST_ERROR` is advertised), and MSRV remains **Rust 1.96**.
Upgrading from 1.0.0 is a drop-in version bump.

Validated end-to-end across all three bindings against CompactLogix hardware
(5069-L330ERM): **2299/2299 reads, 2206/2206 writes, 0 anomalies**, byte-identical
across Rust, C#, and Python.

## Install

```toml
# Rust — Cargo.toml
rust-ethernet-ip = "1.1.0"
```

```xml
<!-- C# -->
<PackageReference Include="RustEtherNetIp" Version="1.1.0" />
```

```bash
# Python
pip install rust-ethernet-ip==1.1.0   # the wheel now bundles the native library
```

## ✨ Added

- **Richer error reporting.** New FFI export `eip_get_last_error` (capability
  `CAP_LAST_ERROR`) exposes the underlying CIP failure reason. C# surfaces it via
  a new `PlcException` (`.NativeError`); Python appends it to `PlcOperationError`
  — e.g. a bad read now reports *"CIP Error 0x04: Path segment error"* instead of
  a generic message.
- **C# asynchronous API.** `ReadDintAsync` / `WriteBoolAsync` / `ReadStringAsync`
  / batch / `CheckHealthAsync` and friends (`Task.Run` wrappers) so calls are
  awaitable and UI threads stay responsive.
- **Working Python wheel.** The wheel now bundles the native library and is
  platform-tagged, so a plain `pip install` yields a functional package.
- New docs: `docs/API_STABILITY.md` (SemVer / MSRV / ABI policy) and
  `docs/MIGRATION_0.7_to_1.0.md`.

## 🐛 Fixed

- **Bit access** (`MyDINT.15`, `read_bit`/`write_bit`) now resolves entirely
  client-side (mask on read, read-modify-write on write); the previous wire
  encoding emitted a malformed logical-member segment. Hardware-validated.
- **C#:** typed UDT writes (`WriteUdt`/`WriteUdtData`) serialize `data` as a byte
  array matching the native `Vec<u8>` (was base64, silently rejected); a failed
  scalar write no longer re-issues the write to harvest an error (which
  double-applied side-effecting writes); added a finalizer and thread-safe
  `Dispose` (no more leaked native sessions or teardown races).
- **`RoutePath::add_port` / `RoutePath.AddPort`** before an address no longer
  silently drops the port (Rust and C#).
- **Python:** a generic UDT is no longer mis-decoded as a STRING (headerless
  decode now requires zero padding and valid UTF-8).
- Subscription `change_threshold` documented as the absolute deadband it
  implements; `TagManager` tag-list parsing reads the item count at the correct
  offset when additional-status words are present; `build.rs`/`version.rs`
  tolerate building without a git checkout (a crates.io tarball).

## 🔧 Changed

- **Dependencies:** `thiserror` 2.0; removed unused `log`/`env_logger`; `tokio`
  trimmed from the `full` feature to the set actually used (`rt-multi-thread`,
  `macros`, `net`, `time`, `sync`, `io-util`).
- **Internal:** the 22 scalar FFI wrappers are macro-generated (ABI-identical);
  the standalone `enip-test` harness and vestigial dead code removed from the
  published crate; the unrunnable `examples/rust_examples/` tree deleted.
- **Release packaging** now builds multi-RID NuGet and per-platform PyPI wheels,
  and publishes the five crates to crates.io in dependency order.
