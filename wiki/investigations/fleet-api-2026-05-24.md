# Fleet API

## Summary

CODEX-T adds an additive Rust `Fleet<PlcId>` API for managing multiple actor-backed `Client` handles. As of CODEX-AQ, it is the maintained replacement for the older `PlcManager` pool, which remains only as deprecated 1.x compatibility surface.

## Current Understanding

- `confirmed`: `Fleet<PlcId>` stores one cloneable actor `Client` per PLC id.
- `confirmed`: `Fleet::events()` forwards per-client `ConnectionEvent` values as `FleetEvent { plc_id, event }`.
- `confirmed`: `Fleet::check_health()` runs health checks across all currently registered PLC clients and returns a per-id result map.
- `confirmed`: the API is additive and does not alter C#, Python, or FFI behavior.
- `confirmed`: CODEX-AQ deprecated `PlcManager` on 2026-07-07 because its `&mut self` API cannot provide concurrent pooled use; 2.0 should remove it rather than continue it as a separate low-level pool.
